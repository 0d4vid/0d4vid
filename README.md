### Focus

- **Retrieval-augmented generation**: indexing complex PDFs and internal documentation, then serving grounded answers to AI tools through MCP
- **LLM integration**: cloud models (Gemini, OpenAI-compatible APIs) and local models through Ollama, with structured outputs
- **Applied machine learning**: recommender systems, embeddings and vector search, computer vision
- **Automation and data pipelines**: n8n workflows, ETL, analysis and dashboards
